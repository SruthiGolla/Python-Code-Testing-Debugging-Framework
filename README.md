# Python Code Testing & Debugging Framework

A beginner-friendly Python project designed to test application behavior, identify bugs, validate edge cases, and compare expected results with actual outputs.

## Project Objective

The goal of this project is to demonstrate practical skills in:

- Python testing
- Debugging
- Test case design
- Edge-case validation
- Error and exception handling
- Expected vs. actual output comparison
- Code quality analysis

## Features

- Automated test execution
- PASS / FAIL / ERROR test results
- Valid and invalid input testing
- Edge-case testing
- Exception handling
- Bug identification and debugging
- Test result documentation
